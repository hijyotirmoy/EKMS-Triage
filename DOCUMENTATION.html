1 Executive Summary & Mission Overview

The EKMS Triage Platform is an enterprise clinical decision support and proximity-routing engine designed to streamline emergency intake, patient severity assessment, and facility navigation for the Employees' State Insurance Scheme (ESIS) healthcare network in Assam.

🎯 Core System Capabilities
• Sub-Second Clinical Triage: Evaluates reported symptoms, assigns clinical urgency tiers (1 to 10 severity scale), and generates bilingual summaries (English & Hindi) in real time.
• Intelligent LLM Reasoning Engine: Employs a high-availability multi-LLM architecture with automatic load balancing and zero-downtime failover.
• Geodesic Proximity Engine: Real-time Haversine distance ranking across 98 authentic ESIC/ESIS hospitals, model dispensaries, and empanelled private tie-up facilities.
• Real-Time Cloud Synchronization: Centralized cloud database synchronization for cases, live facilities directory, caller history, and multi-agent coordination.

4 Multi-LLM Reasoning Engine & Load Balancing

The platform utilizes an enterprise Multi-LLM routing architecture designed for uninterrupted high-throughput reasoning:

⚡ High-Availability LLM Architecture Highlights
• Continuous High Throughput: Distributed multi-channel request routing designed to handle peak call volumes without degradation.
• Instant Dynamic Failover: Zero-delay routing switches requests automatically if rate limits or latency thresholds are encountered.
• Multi-Tier Redundancy: Primary LLM clusters are backed by secondary LLM models and a deterministic algorithmic fallback engine.
• Deterministic Reliability: Guaranteed valid clinical assessments and structured outputs even during unexpected external network disruptions.

5 Facility Proximity & Geodesic Routing

Distances are computed in real-time from the caller's resolved location to all 98 healthcare facilities in Assam using the Haversine Geodesic Distance Formula:

d = 2 · R · arcsin( √( sin²(Δlat / 2) + cos(lat1) · cos(lat2) · sin²(Δlon / 2) ) )
(where R = 6371.0088 km, Earth's mean radius)

Location Resolution Fallback Hierarchy

  1. Direct GPS Coordinates: Highest precision matching (accurate to within meters).
  2. Caller Pincode Match: Centroid resolved across 74 Assam postal zones.
  3. District Headquarters Match: Centroid mapped to district headquarters.
  4. Statewide Centroid: Kamrup Metropolitan / Guwahati (26.1215° N, 91.8085° E).
